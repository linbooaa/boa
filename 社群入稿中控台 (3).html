3. 文案校正

沿用入稿格式整理工具的規則（標點全形、中英空格、商標大小寫），再加上 SOP 檢查：「抽」字、文末逗號、重複 hashtag、FB 專屬 hashtag、內文網址、Expert 系列 emoji 數量。

    4. UTM 與留言連結

    ASUS 網域才帶 code（Social sheet）；PChome／momo／Yahoo 用各自的 sheet 規則；其他電商（燦坤、全國電子、博客來…）只縮網址；蝦皮請交 Mentor。已帶過 code 或縮過的網址會先清乾淨再重新帶。

    #通路處理方式CAMPAIGN_NAME / AD_CONTENTTAGGED_URL縮網址
    Short.io 自動縮網址（選填）

    在 Short.io 後台建立 API key（Integrations & API → 勾選 Public，限定 domain tw.asus.click）後貼在這裡，就能一鍵縮網址；不填則請手動到 Short.io 縮，再把結果貼回表格的「縮網址」欄。Key 只存在這台瀏覽器。

    開啟 Short.io ↗

    欄位順序：DESTINATION_URL｜上線日期｜產品線｜廣告形式｜檔期名稱｜ca/wm｜Optional｜TRAFFIC_SOURCE｜MEDIUM｜KEYWORD｜上線日期｜產品線｜廣告形式｜檔期名稱｜ca/wm｜產品型號｜素材｜受眾包｜類型｜Optional。與實際表不符時請到「設定」調整。

    5. 排程發布（Meta Business Suite）

    任何情況都不要按「立即發布」。部分產品尚未解禁，誤發是嚴重洩密。一律「排定時間」後確認無誤再發布。

      6. 入稿通知信

      雲端入稿無原信，須開新信；信件入稿直接「全部回覆」原信。初期先寄給 Mentor 過目（下方可一鍵包成「以下是我要寄給 ○○ 的入稿通知」）。修改文案的說明請用正向語氣（例如「精簡文案」）。

      「複製成 Outlook 格式」後在 Outlook 新郵件按 Ctrl+V，表格與連結會保留；.eml 檔用 Outlook 桌面版打開會直接是可編輯的草稿（含收件人、CC、截圖）。
